# 🚀 BTK Academy - ASP.NET Core MVC Course Project

A dynamic web application developed as part of the **BTK Academy** ASP.NET Core MVC training series. It covers core MVC architecture, form handling, validation, and in-memory data listing.

---

## 🛠️ Tech Stack

*   **Framework:** .NET 8.0 / 9.0 (ASP.NET Core MVC)
*   **Frontend:** Bootstrap 5, HTML5, CSS3
*   **IDE:** VS Code (Windows)
*   **Version Control:** Git & GitHub

---

## ✨ Features & Key Concepts

*   **MVC Architecture:** Separation of concerns using `Controllers`, `Models`, and `Views`.
*   **Data Management:** Simulated course applications using an In-Memory `Repository` pattern.
*   **Form Validation:** Prevented duplicate registrations via email checks using `ModelState.AddModelError`.
*   **Security:** Secured form submissions using `[ValidateAntiForgeryToken]`.
*   **Responsive UI:** Styled cleanly with Bootstrap for a responsive user experience.
